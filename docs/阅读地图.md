# 阅读地图（阶段 1：3D 地形 + 水系）

入口：阅读器 → 标记抽屉 / 顶部工具栏 → **书中地图** → 右上 **3D 全球地形**。

## 已实现

- **MapLibre GL 6.15 地球投影**：与参考站同一套构造——globe 投影、地形色带、hillshade、独立水系遮罩、河流与河名。
- **两套精选地图**（`src/renderer/pages/atlas/catalog.ts`）：西欧 1940、巴尔干 1940—1941；地点坐标来自 Natural Earth `ne_110m_populated_places`。
- **本地数据**：`src/renderer/public/atlas/relief/**`（85 张 0–3 级 webp，约 514KB）、`rivers.json`（6.0MB）、`water.json`（7.9MB）。构建后复制到 `out/renderer/atlas/`。
- **在线细节**：Mapzen/AWS Terrarium 高程（色带、hillshade、terrain）、OpenFreeMap 矢量水系；失败时保留本地 relief/水系并给出降级提示。
- **交互**：区域全览 / 全球 / 3D 地形三档；地点标记与标签避让；缩放、旋转、重试；键盘 Ctrl/⌘ +/−/0。
- **协议**：生产构建是 `file://`，MapLibre Worker 不能 fetch 本地文件，因此地图资源走主进程的 `spbf-atlas://a/atlas/...`（只放行 `atlas/` 下的 webp/json）；开发态走 Vite 的 http。

## 阶段 2：书中地图图片识别

- 打开/更换书中原图后，渲染层经主进程的 `spbf-map://m/<bookId>` 读取原图字节，算 SHA-256，与精选地图的指纹**精确**比对（先比字节数，再比哈希）。文件名、页号、图片内容相似都不算。
- **识别成功**：原图上按 `imagePoint` 画地点圆点，左侧列出地名；点圆点或地名切到 3D 地图并对准该坐标。
- **未收录**：明确显示「这张地图未收录：按图片字节精确匹配，不做猜测」，不画任何地点。
- 精选地图的原图不随仓库分发；用户需要有与指纹一致的图片才会命中。`identifyBookMap` 支持注入地图清单，单元测试用合成的字节验证命中/不命中两条路径。
- 新增主进程协议 `src/main/mapProtocol.ts`（`spbf-map://m/<bookId>`）：生产构建 `fetch(file://)` 被拦，原图哈希只能走协议读取。

## 阶段 3：文字地名 → 3D 地图

- 复用已有的「书中地名」链路：`ai.extractPlaces` 从正文抽地名，`map.geocodePlaces` 用腾讯地理编码给坐标（模型不产出坐标）。
- 已确认定位（`resolved`）的地名汇总成一张**「书中文字地点」**地图（`atlas/mapPins.ts`）：没有原图，范围由所有地点经纬度算出，跨日期变更线取短弧；地点作为 `atlas-marker` 画在地球/地形上。
- 左侧「书中地名」列表上方显示「已定位 N 个书内地名」，点地名或「查看文字地点地图」切到 3D 并选中该点；3D 区域下拉里多出「书中文字地点」。
- 低可信度待确认（`ambiguous`）的地点不进地图，仍在左侧列表用确认/忽略处理；被忽略的永不上图。
- 没有新增 IPC 或类型；只读 `places.json`，坐标仍由腾讯返回。

## 阶段 4：阅读器左下角地图胶囊

- 阅读器左下角出现两半胶囊（有已识别图片地图 / 已定位文字地点时才出现）：左半图片地图、右半文字地点汇总。没有数据的那一半置灰。
- 点任一半打开**非模态迷你 3D 面板**（约 1/3 宽、1/2 高）；`⤢/⤡` 原地放大/收起，`×` 或 Esc 关闭；面板底部可跳到完整的「书中地图」抽屉。
- 迷你地图用 `compact` 模式：MapLibre 不抢键盘，左右方向键仍归阅读器翻页；Ctrl/⌘ 缩放仍可用。
- 数据复用现有的 `map.getImage` / `map.getPlaces`：图片按 SHA-256 识别，文字地点按已确认坐标汇总；不新建账号/云同步/删除状态。
- 参考站的「逐地点删除」「结果说明页」「原文锚点跳转」没有搬；文字地点面板只做地图与跳页，原文跳转仍在完整地图页里。

## 数据与署名

- 地形瓦片：Mapzen terrain / Tilezen + Natural Earth land mask；署名随图显示。
- 水系与河网：Natural Earth 1:10m 物理矢量（公共领域）；OpenFreeMap 详细水系 © OpenStreetMap contributors。
- 精选城市坐标：Natural Earth `ne_110m_populated_places`。
- 完整来源与哈希见 `src/renderer/public/atlas/README.md`。
- `maplibre-gl` 为 BSD-3-Clause，许可文本在 `third_party/maplibre-gl/LICENSE.txt`。

## 技术边界

- 新增依赖 `maplibre-gl@6.15.0`（纯 JS/WebGL，无 native）。
- `AtlasMap.vue` 由参考站的 `AtlasMap.tsx` 改成 Vue；`atlas/` 下的 catalog / terrainView / mapStyle / hydrology 为 Apache-2.0 搬运并适配。
- MapLibre 的 Worker 以 `?raw` 读入后包成 `Blob` URL，避开 `file://` 下 Worker 脚本被拦。
- 阶段 1 **不含**：书中地图图片识别、文字地名识别、阅读器左下角 dock、账号/云同步；也没有参考站的 800MB GeoNames 地名库。
