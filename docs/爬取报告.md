## 四、抓取过程要点（供复现）

- 主站与镜像的可用性会来回漂移：`www.alicesw.com`、`www.alicesw1.homes`、`alicesw4.homes` 三者交替可用，抓取器按「宿主健康度」自动切换（5xx 拉黑 90s）。
- 站点限流按出口 IP：单 IP 突发约 6 rps 时约 350~360 次请求后返回 HTTP 444；降到 1 req/s 可长期不被封。持续高并发还会触发 Cloudflare 521/522，负载停下约 90 秒即恢复。
- 因此用 8 个 mihomo 出口（7897~7904，external-controller 9090~9097）轮换节点，全局并发 96、每出口 300 次请求后换节点，稳定在 25~45 章/秒。
- 工具链：`.probe-cf/crawl/crawl11.mjs`（抓取）、`reindex.mjs`（重建索引）、`verify4.mjs`（校验）、`mklib3.mjs`（书目清单）、`watch.ps1`（守护重启）。
