# 小说浏览器 · 需求说明（第一版）

状态：已确认，可作为开工依据  
日期：2026-08-13  
形态：Windows 桌面、单机自用  
范围口径：以 `AGENTS.md` 为准。本文件与它冲突的范围条目，一律按 `AGENTS.md` 记为「第一版未实现、后续可做」；已经实现的行为仍以代码和 `docs/ipc-contract.md`、`docs/disk-schema.md` 为准。

---

## 1. 一句话

把小说站网址贴进软件，在内置浏览器里看网页；对当前这本书点「下载本书」，整本进本地书库；用阅读器接着看；用自己的 API Key 调用 AI 清正文、摘要追剧、翻译、聊书。已有的 txt / epub 也能导入同一书库。

## 2. 这不是什么

- 第一版按「一本书」下载，不是整站离线镜像（整站镜像 `AGENTS.md` 允许后续做）
- 按通用规则提取，什么站都可以试；本机可按域名配站点 CSS 规则（已实现），站点规则市场第一版没有
- 不是网文分发 / 分享平台
- 付费 / 需登录 / 被拦截只做成失败分类，给可读原因和重试入口；不做绕过付费墙、不做对抗反爬（这几项是范围之外，不是排期问题）
- 第一版是单机自用：没有账号、云同步、多设备、手机端（账号 / 云同步 `AGENTS.md` 允许后续做）

法律定位：**个人阅读工具**。用户对自己粘贴的网址和下载内容负责。

## 3. 谁、在什么场景用

使用者就是你自己。典型路径：

1. 从浏览器或别人处复制一本小说的目录页（或任意章节页）链接
2. 贴进本软件，内置浏览器打开，可登录站点、点目录、翻章
3. 确认是要下的那本书后，点「下载本书」
4. 书库里出现一本可打开的书，章节齐全
5. 阅读器里看，下次打开还在上次的位置
6. 需要时让 AI 清正文、写摘要、翻译选中文字、按这本书提问
7. 以前下好的 txt / epub 也丢进同一个书库

## 4. 模块与验收

### 4.1 内置浏览器

**要做**

- 地址栏：粘贴 / 输入网址后打开页面
- 页面可点击链接、滚动、提交表单（以便登录小说站）
- 基本导航：后退、前进、刷新、停止
- 当前页与「下载本书」关联：下载针对**当前正在看的这本书**，不是整站

**第一版不做**

- 当完整日常浏览器（扩展、多账户配置文件等）
- 整站收藏夹式离线（第一版没有，归入 `AGENTS.md` 允许的整站镜像）

**验收**

- 粘贴任意 http(s) 链接能打开
- 能在常见小说站完成登录（若站点需要）
- 从目录点进某一章，地址和页面随之变化

### 4.2 下载本书

**成功标准（硬性）**

> 在一本书的目录页（或能识别出该书的章节页）点「下载本书」→ 书库中出现一本可点开的书 → 打开后目录完整、正文按章可读。

**行为**

- 目标粒度是**一本书**，不是一个域名
- 采用**通用提取**：目录识别、章节链接、正文抽取，不绑死单一站点
- 「什么站都想试」：不保证每个站 100% 成功；失败时给出可读原因（找不到目录 / 正文为空 / 需要登录 / 需要付费 / 被拦截），并允许重试或只补下失败章节
- 下载过程可见进度（已下 x / 共 y 章）；支持取消
- 同一本书再次下载：更新缺失或失败的章节，不无故复制成两本
- 尊重站点需要登录的事实：用内置浏览器里已有的登录态去拉章节，不为破解付费章做专门功能（付费 / 需登录 / 被拦截按 `FailCode` 分类返回可读原因）
- 同类墙连撞三章就停在那一章：把这一章在内置浏览页打开，由你本人登录 / 购买 / 通过验证，你确认处理好后才只补因墙失败的章节；软件不代你登录、不代你付费、不代你点验证

**第一版不做**

- 站点 CSS 选择器市场（`AGENTS.md` 允许后续做，第一版只有本机按域名配规则）；用户写复杂爬虫脚本不做
- 批量「把这个作者/分类全部下完」（第一版按一本书下，整站镜像 `AGENTS.md` 允许后续做）
- 验证码自动打码、IP 池、专门反反爬：范围之外，不排期

**验收样例（实现时用你常用的 1～2 个站验证）**

- 免费目录完整的书：一键下完，章数与目录一致，正文不是导航/广告残页
- 需要登录才能看正文的书：浏览器已登录的前提下能下；未登录时明确提示
- 结构怪异或失败的站：不崩溃，有失败说明

### 4.3 书库

**要做**

- 列出已下载和已导入的书（封面若无可用占位、书名、作者若能识别、阅读进度）
- 卡片显示 AI 全书概览前两三行，可原地展开全文，并标明“含剧透”；与只根据已读内容生成的前情提要分开
- AI 设置中的自动概览默认关闭；用户保存开启后，完整入库的已有书与新书串行生成，失败可重试，正文变化后更新
- 打开进入阅读器
- 删除书（删本地对应数据）
- **导入**已有 `.txt`、`.epub`，导入后与下载的书同等对待

**txt 导入**

- 按常见网文章节标题切分（如 `第x章`）；切不出则整本一章，仍可阅读

**epub 导入**

- 使用文件自带目录；正文按 spine / 章节进入阅读器

**验收**

- 下载完成的书立刻出现在书库并可以打开
- 导入一本带「第x章」的 txt，目录可跳转
- 导入一本正常 epub，目录与正文对应
- 删除后书库与磁盘数据都去掉

### 4.4 阅读器

**要做（最低集，已确认）**

- 目录跳转
- 记住看到哪（书 + 章 + 章内位置）；下次打开同一本恢复
- 字体大小、行距、夜间模式

**交互底线**

- 上一章 / 下一章
- 滚动阅读（长章不必一屏一页硬翻，第一版以滚动为主即可）

**第一版可不做**

- 全文搜索、多书签、划线笔记、导出、朗读（TTS）
- 双开对照、漫画/图片书

**验收**

- 从目录点任意章能跳到该章
- 退出软件再打开，回到上次的书、章、大致位置
- 改字体、行距、夜间后立即生效，并记住偏好

### 4.5 AI（四项都做，用你自己的 API Key）

软件内配置 API Key（本地保存，不上传到我们自己的服务器——第一版也没有这种服务器）。

| 能力 | 做什么 | 验收 |
|---|---|---|
| 清正文 | 去掉残留导航、推荐位、作者有话说之外的广告/乱码，得到可读书章 | 对「能下但很脏」的一章，一键清理后正文明显更干净；可撤销/保留双份中的一份策略在实现时定，默认覆盖前先可预览 |
| 摘要追剧 | 按章或按已读进度生成摘要；续看时用摘要回忆前情 | 对已读章节能生成不剧透未读部分的摘要 |
| 翻译 | 选中原文得到译文或释义 | 选一段外文或文言，返回对应译文；不必整本机翻 |
| 聊书 | 基于当前书（至少当前章 + 目录/已读摘要）提问 | 能问人物关系、情节、推荐同类；回答应能看出读过这本书，而不是泛泛闲聊 |

**约束**

- AI 失败（没填 Key、额度、网络）不影响浏览、下载、阅读
- 第一版按「当前书 / 当前章」为上下文，不做全网检索式推荐站
- 具体供应商（OpenAI 兼容 / Anthropic / 其他）在实现时做成可配置的接口地址 + 模型名 + Key，避免绑死一家

## 5. 数据与隐私

- 书、进度、设置、API Key 只存在本机
- 第一版无注册、无云同步（账号 / 云同步是 `AGENTS.md` 允许的范围，真做了才会有书库数据离开本机）
- 上网行为：内置浏览访问用户指定的站点；下载请求发往这些站点；AI 请求发往用户配置的模型服务（会带上用户选中的文本/章节）
- 浏览页去广告开启时，应用会从 AdGuard 官方地址下载并缓存 AdGuard Base 网络规则；网络过滤仅处理浏览 View 的请求，不处理下载 View。
- 不把书库内容发到任何未经用户触发的第三方

## 6. 非功能

- 系统：Windows 10/11 x64
- 一本数百章的书应能下完并打开；单章极大时阅读器不卡死（可后加载）
- 下载中途断网：已下章节保留，可续下
- 界面中文

## 7. 范围分层（与 `AGENTS.md` 对齐）

**`AGENTS.md` 允许、第一版未实现**（后续要做得先补契约与类型，不是顺手加）：

- 整站镜像
- 站点 CSS 选择器市场（分享 / 订阅抽取规则）
- 账号体系、云同步、多设备

**两份文档都不做**：

- iOS / Android
- 社区、评论、分享导出到公网
- 浏览器扩展版、命令行版
- 自动更新全书追更调度的复杂系统（可先留「检查更新」入口，第一版能手动重新下载/补章即可）
- 用户自写复杂爬虫脚本

**范围之外，不是排期问题**：绕过付费墙、验证码自动打码、IP 池与代理轮换、专门反反爬。这几项是绕过站点自身的访问控制与反滥用机制，本项目只做到「识别并如实说明失败」，不实现绕过。**允许的是**：用户用自己的账号在内置浏览页亲自登录或通过验证，之后用这份已有登录态续下原本就对他开放的章节（见 §4.2）。

## 8. 实现默认值（已拍板）

- 技术栈：Electron + electron-vite + Vue 3 + TypeScript + Naive UI
- 书文件：每书一目录；每章 `chapters/NNNN.json`（纯文本 `body` + 可选 `bodyRaw`）；导入源文件放 `origin/`。详见 `docs/disk-schema.md`
- 清正文：先预览，确认后只改 `body`；撤销用 `bodyRaw` 恢复
- AI：OpenAI 兼容协议；设置项为 `baseURL` + `model` + `apiKey`；表单 placeholder：`https://api.deepseek.com/v1` / `deepseek-chat`。不预置官方 Key
- 窗口：左侧窄侧栏切换「浏览 / 书库 / 阅读 / 设置」
- 书库默认路径：`D:\spbf\library`（设置可改）

## 9. 第一版完成的定义

同时满足：

1. 粘贴链接，能在软件里浏览并登录小说站  
2. 对一本书点「下载本书」，书库出现章节齐全、可打开的书  
3. 通用提取，不限定单一站点；失败有说明  
4. 阅读器：目录、进度、字体/行距/夜间  
5. txt、epub 可导入同一书库  
6. 配置自己的 API Key 后，清正文、摘要追剧、翻译、聊书四项都能在一本书上跑通  
7. 第一版交付时仍是单机、无账号：整站镜像、站点规则市场、账号 / 云同步都未实现；付费墙与反爬只做失败分类，不绕过；不分发
