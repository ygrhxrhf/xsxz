# 真实书籍 WebGL 复刻

## 开关

阅读界面 → 真实书籍 → 展开底栏 → **背景** → **书籍渲染**：

- **WebGL 3D**：Three.js 书体、双页纹理、书脊/封面/页堆、开合与翻页、视角与缩放。
- **CSS 3D 回退**：原来的 DOM 文本 + CSS 3D 实现，保留批注、选字和既有 E2E。

选择存本机 `localStorage`，不写入 `ReaderPrefs`，不跨设备同步（默认走 WebGL 时不会主动写这个键，只有用户显式选过才写）。支持 WebGL 的机器默认进入 WebGL 3D；用户显式选过 CSS 3D 或环境不支持 WebGL 时才回退。

## 已实现

- 书页渲染层换成 **LeafMesh + 纸质 shader**（源自 Infinite Reader，Apache-2.0）：双面网格按 `gl_FrontFacing` 选正/背页纹理，纸背按 U 反采样；加入透字（飞页 16%，静态页关闭）、背光透射（翻到侧对镜头时发暖）、曲率暗化、纸纤维、边缘压暗。飞页与静态页共用同一材质（静态页的中缝已画进纹理，`uGutter` 置 0），落页前后不会换一种亮度；静态页的曲率写进 `aCurv`，预掀/落回时重算。运动仍由 `realBookCloth` 的解析弧面 + 弹簧布料驱动，`LeafSim` 只作为飞页的网格载体。
- 固定 `640×920` 逻辑页、2× 分辨率页面纹理；分页器现在把每页的真实断行一起交给纹理层。
- 双页摊开、布面书壳（圆背 + 柔性接缝 + 头/尾布条）、硬壳封面、封内衬纸、左右纸垛厚度、桌面材质和基础灯光/阴影。
- 垂直堆叠：桌面 → 后书板 → 书垛 → 书页。书垛从后书板顶面往上长，书页随书厚升高；合上时前封面绕书脊落到书垛顶，打开时前封面落回桌面一侧。
- 自动翻页：飞行页正反面纹理，WebGL 0.4s 行程（`WEBGL_FLIP_DURATION_MS`，对齐参考站的 quick 翻页）。解析弧面由 `realBookFlip` 的纸角/书脊双时间线给出，**叠在它上面的是 40×8 质点布料**（`realBookCloth.ts`）：中间鼓起、两个自由角下垂、沿页高有行波，质点带弹簧-阻尼惯性（阻尼比 0.43，落位有余颤），再沿网格把偏离抹成低频，书脊侧全程钉死在中缝上；渲染网格交给 `LeafMesh` 的 40×26 顶点（沿页高用 Catmull-Rom 取样）。进度带弹簧滞后/回弹，弹簧按真实帧间隔推进。**页间自阴影**：飞页把页脚/页心/页眉三条截面（各 20 个采样点）写进共享的浮点纹理（`shadowRig`），接收纸面在纸质 shader 里沿灯光射线与截面求交，得到跟着纸形走的软影与半影；最上面的两张纸同时发布，透明度随落定包络衰减。静态页永远是接收面，飞行纸也能接收上面那张的投影。
- 纸背贴图按 U 取反（对应 CSS 3D 回退里的 `scaleX(-1)`）：纸转过 90° 后几何的 u 轴在屏幕上是反的，不预翻一次纸上的字就是左右颠倒的。
- 往回翻是同一段弧面的**倒放**而不是把 x 取反：倒放让纸起手贴在左页、落回右页，贴图不会被镜像；取反 x 会让落定那一帧的字是反的。弧面永远从「右页平躺、正面朝上」量到「左页平躺、纸背朝上」，所以正面网格一定印右页、纸背网格一定印左页；往回翻时两页互换（`flyerFacePages`），否则起手会在左页闪出上一张右页的内容、落定后右页又跳回它。
- 合上/打开书籍；底栏按钮状态通过 `update:open` 回传 Reader。合上时相机俯仰自动收到 28%，封面接近正对；打开过程里俯仰连续回到用户设定的视角，不会切一刀。
- 沉浸式 chrome：真实书籍不摆应用顶栏（页面上没有标题条与搜索/标记等入口），工具集中在底栏图标带；底栏末尾新增「更多」，收进搜索、标记、书中地图、朗读、AI、字体/排版、平放、快捷键、沉浸模式、设置、浏览与书架。朗读/AI/快捷键浮层挂在右上角，与底栏同为暗色。页码保留一条隐藏文本，测试与 E2E 仍能读到当前位置。
- 目录/标记抽屉在真实书籍里刷成暗色左侧面板（参考站同款）：暗底奶油白字、烫金选中页签与当前章，过滤器/列表/标签跟随暗色主题；经典模式仍是浅色抽屉。
- 封面：深蓝布面、无边框，标题按封面宽度反算字号并在中文标点处断行，作者作小字副题；封面与后书板向内收 `joint`，由 `CaseBinding` 的布面书壳接起来：圆背、柔性接缝、凹槽衬里和头/尾布条，合上时左侧读出的是一条布面书脊。
- 页眉页脚：左页印书名、右页印章节名（参考站语义），页脚印页码（空页不印）；飞页的正反面按纸所在的一侧取同一规则。页眉是正体小字，不用斜体。文字与正文一起走 DOM 文本层（字号/基线由排版计划给出），静态页与顶层飞页都是矢量字；只有多飞页时非顶层那张仍画在纹理里。
- 相机：`24°` FOV、默认 25° 俯仰、平视 1° / 斜视 52°、最大 62°；右键或 Alt 拖动调整视角；`T` 在 WebGL 真实书籍里循环视角预设。
- 缩放：默认 90%，范围 12%–700%；底栏 ± 按 ×0.8/×1.25，滚轮缩放，复原回到 90%；「适应屏幕」按钮与 0 键把整本书收进视口（100%，即参考站的 fit-book）。
- 阅读外观：胡桃木/亚麻/石墨/鼠尾草/石灰岩桌面（使用采集的 webp 贴图），象牙白/沙色/板岩/鼠尾草/勃艮第红衬纸，存本机。真实书籍底栏的「背景」「字体」浮层刷成与底栏同色的暗色浮层（参考站同款），选项按钮、说明文字与进度条同步换成暗底浅字；经典模式仍用浅色浮层。
- 纸色与桌面照参考站校过：纸面受光约 `#E6D6BF`（参考站约 `#EDD7BA`），桌面受光约 `#46342A`（参考站约 `#46352F`）。主光从琥珀色改成暖白（`#fff6ec`），环境光取中性，右前补光把外口侧提亮；曝光 1.06。桌面贴图按可见桌区平铺 16 次（否则屏幕上只是贴图中央的一小块，木纹被拉平），并用 canvas filter 降饱和、提亮。封面同步改成更深的藏蓝，合上时读得出布面而不是灰板。
- 书页字体：内置霞鹜文楷（`lxgw-wenkai-screen-webfont`，按 unicode-range 分片）；真实书籍默认 22px / 行距 1.5（参考站版心），Reader 的字号/行距偏好按比例换算；外观面板的「书籍字体」可在霞鹜文楷/宋体/黑体/等宽间切换（`bookFontFamily`）。首屏量断行前会等当前正文用到的字体分片落下来，分片晚到会重排一次，不会先按回退字体算一版页表。仍画正文的纹理（多飞页时非最上面那张）额外描 0.012em 的细边，补回纹理缩小后的笔画重量；走 DOM 的静态页与顶层飞页是浏览器直接排的矢量字。
- 透明命中层：按 WebGL 书体屏幕投影给 Reader 做左右三分区翻页。
- 可见 DOM 正文层：静态页的正文、页眉页脚、页内注卡、图片、段内划线与「注」点都由 DOM 显示（纹理里不再画这些内容），按页角投影贴到 WebGL 书页；纹理只保留纸面。选字、划线、批注、跨页选择都在正文这层上，字是矢量清晰的。翻页时只藏被翻走的那一侧，落位前另一侧也暂时收起。
- 飞页正文跟随卷曲：最上面那张飞页的正文按行切成不超过 96px 的小段（`realBookFlyerText.ts`），每帧从布料**当前**形状取每段左上/右上/左下三个角的屏幕投影，用 `matrix3d` 把这一小段字贴到纸面上；纸怎么卷、字就怎么弯，翻过 90° 自动换到另一面，正反面各印哪一页与纹理共用同一个 `flyerFacePages`。飞页纹理因此也不再画正文（与静态页同一张纸面纹理），只在多张纸同飞时，除最上面那张外仍用带字纹理。
- 多飞页并发：快速连翻时最多 6 张纸同时在飞（`RealBookStage` 的 `flips` 纸链 + 场景的 6 个飞页槽位）。后一张纸等前一张走过 17.5%（0.07s / 0.4s）才开始动，几页是「追着翻」的；落定仍按链的顺序提交，页面内容不会被后来的纸提前改写。总时长是首张 0.4s + 后续每张 0.07s。CSS 3D 回退只有一张纸，多出来的方向照旧排队。
- 拖页：从书页左右外缘按住**跟手拖动**，纸严格跟着手指走（拖页中关掉弹簧惯性，见 `flipFollow`）；松手时按走过的比例与甩动速度决定落定还是取消。取消时纸用 0.32× 时长弹回原位、页面内容不变；落定则从手指停下的进度接着走完剩下的行程（时长短一半）。拖不到起拖阈值（10px）按点按处理，不会让一次点击把纸掀一下再弹回去。正文区拖拽仍用于选字。
- 快速连按/连点：翻页动画中最多排队 12 条方向，落定后依次消费。
- 窄屏单页：窗口宽度小于 768 时只显示当前页，逻辑页按视口重排，字号固定参考站的 20px 档（不沿用桌面字号偏好），舞台切纵向 flex 让单页铺满视口；也可用 `localStorage["spore:reader-realbook-phone:v1"]="1"` 强制进入。
- 窄屏卷页：单页模式不再走双页的弧面布料，改用 `phoneCurl` 的滚动折——纸绕一条会走的折线卷起，没被卷到的字保持平坦，卷过 90° 后正反面由 shader 换面；正文改由纹理携带（卷曲处 DOM 小段会叠在一起）。
- 页面纹理光栅化在 Worker（OffscreenCanvas）：主线程只建计划、管缓存，Worker 画完回传 ImageBitmap；按页面用到的字挑字体子集，LRU 64 张。Worker 不可用（或字体/图片准备失败）时回退主线程 `drawPageTexture`。
- 批注与划线：划线/搜索高亮的底色块和段内「注」点按与纹理同一套几何由 DOM 画（`highlightRects` / `noteDots`），底色在字下面、「注」点在字上面；注卡的底纹、标签、正文与 `#tag` 也由 DOM 按同一套坐标排出来，点整张注卡即可打开该条批注；红/紫划线不再回落成黄色。
- 页内图片：EPUB 导入时把章内 `<img>` 抽到书目录 `images/`；下载章节时从页面 HTML 里筛出正文图（过滤站标/头像/广告/占位图，按文件头验证），在隐藏页上下文里带会话取图后存进 `images/`。正文写成 `[图]<文件>|<宽>|<高>|<图注>` 段落；分页器按版心宽度把图片换算成占多少行。静态页与顶层飞页用 DOM 渲染（`img` + `object-fit: contain` + 图注），飞页上整块跟着纸面卷曲；仍用纹理带字的飞页才把图 contain 画进纹理。图片由主进程的 `spbf-image://i/<bookId>/<文件>` 协议读取（开了 CORS，画进 canvas 不会污染成黑块）。CSS 3D 回退用同一协议在页内放 `<figure><img>` + 图注，高度与分页预留一致。
- 书口注释标签：页内注卡在纸的外口贴出「注」标签，位置来自同一份排版结果，随纸页一起做 3D 变换；点标签直接打开该条批注。
- 悬停预掀：指针进入外缘 30px、靠近上/下角时，纸角先翘起一小块（`realBookPeel.ts`，40×26 顶点实时形变 + 平滑缓动）；移开、翻页或合上时落回。

## 未实现 / 已知限制

- 飞页已是 40×8 质点布料 + 惯性；软影用三条截面、每条 20 个采样点近似整张纸，跨页高的细节（比如上下角同时翘起）会被折中；多张纸叠得很近时影子边界仍可能有误差。
- 下载章节的配图按原位落版：抽取前把合格 `<img>` 换成文本标记，正文抽出来天然带着图片位置，下载器再按标记原位换成 `[图]` 段落；续页里的标记也会一起合并。没有标记的路径（章节接口解锁、OCR）退回把图追加到章末。跨域图片被 CORS 拦下时跳过。
- EPUB 导出会把 `[图]` 段落写成 `<figure><img/><figcaption/>`，图片按需塞进 `OEBPS/images/` 并登记 manifest；同一张图跨章只放一份，缺图时退化成「［图片缺失：…］」。TXT 导出没有承载位置，图片退化成「［图片：图注］」一行。
- 多张飞页并发时，只有最上面那张走 DOM 正文；其余各张仍用带字纹理（放大看略软）。DOM 永远画在 canvas 之上，下层的字会盖到上层的纸面上，只能这样取舍。
- 飞页的注卡、图片、划线底色与「注」点也走 DOM（文字逐行、图片/注卡整块贴面），只有多飞页时非顶层那张仍整体画在纹理里。
- 拖页期间不起新纸（同时只有一根手指）；连翻超过 6 张的部分仍走队列。
- 反方向的连翻（往后翻一张又立刻往回翻）不并发，按队列串行。
- 手机单页已可用，但字号沿用用户偏好（参考站固定 20px），未做手机专属字号档。
- 卷页的 `grabV/pointerV` 目前固定 0.5：折线水平横过页心，没有按手指的竖直位置倾斜；单页背面/软影按同一套几何走。
- 桌面贴图来自采集的 webp；衬纸仍是程序化色板。封面是程序化布面（参考站同样程序化），同一本书的封面只随书名/作者变化。

## 技术边界

- 新增 `RealBookWebGLStage.vue` 作为 `RealBookStage.vue` 的渲染子层，分页、锚点、进度和批注数据仍由父组件提供。
- 新增 `realBookTexture.ts` 负责页面纹理计划与 Canvas 绘制（计划里同时给出页眉页脚的字号与 alphabetic 基线，DOM 文本层按同一组数值贴字）；`realBookWebGLModel.ts` 负责可测试的相机/厚度/色板数值；`realBookWebGLScene.ts` 是 Three.js 场景；`realBookCloth.ts` 是飞页的布料场与质点解算（纯函数 + 固定子步，可单测）；`realBookFlyerText.ts` 负责飞页正文的切段、正反面页心分配与贴面矩阵（纯函数，可单测）；`realBookBlocks.ts` 负责页内注卡/图片的 DOM 排版（与纹理同一套字号、缩进、行距、断行；纯函数，可单测）；`realBookTextLayer.ts` 负责页角单应、划线底色与「注」点的几何（纯函数，可单测）；`realBookFlipShadow.ts` 保留为未接入的网格阴影实现（纯函数 + 单测），当前软影改由 `realBookPaperMaterial.ts` 的 `shadowRig` 生成。
- 正文 DOM 图层的逻辑页尺寸跟随分页器：桌面 640×920，窄屏单页用视口重排后的 `pageWidth/pageHeight`。此前固定 640×920，手机会把超出 640 的行画到纸外。
- 新增 JS 依赖 `three@0.187.0`，无 native 模块。
- 新增 `realBookLeafSim.ts` / `realBookLeafMesh.ts` / `realBookPaperMaterial.ts` / `realBookGutterFold.ts` / `realBookPhoneCurl.ts` / `realBookCaseBinding.ts`，源自 Infinite Reader 的 `web/src/engine/`（Apache-2.0）；许可与署名见 `third_party/infinite-reader/` 与 `THIRD-PARTY-NOTICES.md`。纸质 shader 的解析软影（`shadowRig`）已接入：飞页发布截面，静态页与飞行纸接收。书板改用 `RoundedBoxGeometry`（three addons，无 native 模块）；窄屏单页的卷页几何已接入 `phoneCurl`。
- 新增 `realBookTextureWorker.ts` / `realBookTextureRasterizer.ts` / `realBookFontFaces.ts`，以及主进程 `fontProtocol.ts`：构建后页面是 file://，Worker 取不到 file:// 字体，`spbf-font://f/<name>.woff2` 只放行 `out/renderer`（含 `assets/`）下的 `.woff2`。`src/preload/index.ts`、`src/shared/types.ts` 与 IPC 契约未改动。
