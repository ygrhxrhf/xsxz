# 计划：最近在读改成一排横向卡片

> 规则：勾选必须有命令证据。没有跑过的项不许勾成 `[x]`。

## 目标

书架顶端不再只显示一本「最近在读」：本地书与网页书按最近阅读时间排成一排卡片
（最多 20 本），可以左右滚动（箭头、触控板横扫、竖向滚轮在条内换算成横向），点哪本读哪本。

## 步骤

- [x] 1. 数据：把单本 `continueItem/continueView` 换成 `recentItems/recentViews`，两种来源合并排序后取前 20
      - 验：`npx vitest run src/renderer/pages/Library.recentWeb.ui.test.ts` → 4 条通过（含「两本都还在排里」）
- [x] 2. 交互：一排横向滚动（`scroll-snap`）、左右箭头挪一屏多一点、竖向滚轮换算成横向并在到头时还给页面
      - 验：同上（箭头调用 `scrollBy`、jsdom 无布局时滚轮不拦截）
- [x] 3. 样式：268px 卡片、72×100 封面、最新一本保留赭红竖线、隐藏横向滚动条
      - 验：`git diff src/renderer/pages/Library.vue` → `.shelf-recent*` 取代 `.shelf-continue*`
- [x] 4. 头图按钮：顶部「继续读」点开最新一本
      - 验：`Library.ui.contract.test.ts` 13 条通过
- [x] 5. 构建与重启应用
      - 验：`npm run build`；重启后进程树含 renderer，`out/renderer` 含新代码
- [x] 6. 提交：`feat(library): 最近在读改成一排横向卡片`
      - 验：`git log --oneline -1`

## 不做（显式出范围）

- 不做自动轮播：由读者自己滑动。
- 不把「最近在读」并入下面的书库网格（两者职责不同：一个续读，一个全量筛选）。

## 已知边界

- 最多 20 本：再多对首屏续读没有意义，也会拖慢渲染。
- 只有存在阅读进度的书才进这一排；没读过的书在下面书库里。
