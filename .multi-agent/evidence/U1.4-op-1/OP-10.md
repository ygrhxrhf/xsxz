# OP-10：同章「请收藏这封信」整段应可见

清单原文：同一章有一段「请收藏这封信」且不含本站/网址/地址。应看到该段可见。

## 截图
- `OP-10.png`（1280×771，同一实例同一章，工具层已收起）
- 读数字节：`OP-10-state.json`

## 该段读数（`data-p=2`）
```
rect = x384 y250 554×32
visibleArea = 17944 px²（视口内实际可见面积）
display=block  visibility=visible  opacity=1  coveredByOther=false  onScreen=true
text = 请收藏这封信。信上只写了三行字，字迹很轻，末尾没有署名。
```

## 屏幕上实际可见文字（逐段）
与 OP-9 同一屏：p=0 / p=2 / p=3 / p=4 / p=5 / p=6 / p=7 / p=8 共 8 段，`visibleTextOnScreen` 第二行即
`请收藏这封信。信上只写了三行字，字迹很轻，末尾没有署名。`

- 该句所在样章正文（磁盘 `chapters/0001.json`）为
  `请收藏这封信。信上只写了三行字，字迹很轻，末尾没有署名。`
  —— 含「请收藏」但**不含**「本站」「网址」「地址」，也不含任何域名。
- 像素侧：`OP-10.png` 在 y=258..275 有一条 x=421..911 的整行墨迹，正是这一段；`_ink-bands.json` 里该行带 `{y0:258,y1:275,maxDark:140}`。
- 无障碍树 `_ax-chapter1.txt`（第一章）有 `StaticText 请收藏这封信。信上只写了三行字，字迹很轻，末尾没有署名。`。

## 说明：与 OP-9 同帧
OP-10 与 OP-9 之间没有任何输入事件，`OP-10.png` 与 `OP-9.png` 字节相同（md5 `b260513faf…`），同帧同时回答两条
清单问题。该段单独裁片见 `_crop-OP-10-keep.png`（x340..1010 / y230..300，2 倍放大）。

## 结论（只报事实）
见到的：该段作为一个正常正文段落在屏幕上显示，有布局盒、无遮挡、有墨迹，可被无障碍树读出。
