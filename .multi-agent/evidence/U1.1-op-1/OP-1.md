# OP-1 操作记录

清单原文：OP-1：打开一本有进度的书，不移动鼠标。应看到正文和左侧书脊。看不见顶栏，看不见「目录」「进度」「背景」「字体」。

操作：指定实例启动后自动进入独立样例书第二章。为记录点开路径，先点正文 (666,385) 展开工具，点「书架」(448,27)，记录入口 OP-1-before.png，再点「最近在读」书卡 (300,385)。点击采用 CDP 原生鼠标按下/释放；点开后未发送 mouseMoved，也未滚轮。该书卡写明「样例·长夜行舟」「样例作者」「读到第 2 章 / 共 3 章」。

实际记录：OP-1.png 显示「第二章 样例长夜」和第1至第5段纸面正文，左侧书脊「样」。顶栏当时仍显示「样例·长夜行舟、书架、搜索、标记、朗读、AI、设置、浏览」，右侧显示「目录、进度、背景、字体」。该次进入复用了先前展开工具的阅读页面状态；完整保留，不用后续截图覆盖。

补充操作：对同一 CDP target 执行 Page.reload，未发送鼠标移动，重新读取已存的第二章。OP-1-fresh.png 记录此重新载入状态：正文与左侧「样」仍在，顶栏 visibility=hidden、opacity=0、高度0；四个右侧按钮 visibility=hidden。正文起始文字为「第1段：夜色沿着河岸缓缓展开，船上的灯光照亮纸页」。此补充状态是后续 OP-2 的起点。
