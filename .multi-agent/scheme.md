## 一句话目标

使用者打开有进度的书时只见暖纸正文和左侧书脊；点正文可翻屏或唤出工具；拖进度到章首；整段站点尾巴默认不显示，章节文件不变。

## 完成定义

1. 有阅读进度时，启动后主区是上次那本书的暖纸正文。顶栏和右侧「目录 / 进度 / 背景 / 字体」默认不可见。左侧书脊仍在，点书脊回书架。没有书时仍显示「阅读」「从书库打开一本书后在这里阅读」和「返回书库」。
2. 点正文中间三分之一，顶栏与右侧胶囊出现，顶栏含「搜索」。再点中间一次，或在没有已开面板时按 Esc，工具收起。点左侧三分之一上一屏，点右侧三分之一下一屏。滚轮仍滚动。左/右方向键仍是上一章/下一章。空格与 J/K 仍翻屏。
3. 底部进度条可拖。拖动时显示目标章名。松手打开该章并位于章首。拖到失败章停在该章，失败说明、重试、去浏览页仍在正文区。
4. 字体面板点「屏幕翻页」后，翻屏落在段落边界：被切断的短段下一屏从该段段首开始；一段高于一屏时只前进不超过一屏，不跳过该段剩余文字。点「连续滚动」后不再吸附。默认仍是连续滚动。
5. 默认开启净化。空行切成的一整段去掉空白后命中内置尾巴规则时，该段不显示。「请收藏这封信」这类叙述段仍显示。字体面板「本章显示原文」只让当前章临时显示原文，换章或重开书恢复净化。章节文件、划线、搜索、听书位置不改。关掉「净化」后重开书，尾巴段可见。
6. 当前书下载状态为 running 时，不点正文也能看见「已下 x / y 章」和「取消」。下载结束或取消后，顶栏回到默认收起。旧书不用重建。

## 选定理由

功能已经齐。缺口是默认阅读动作仍被工具和整屏硬切打断。微信读书用点中间出工具，Legado 用翻页模式加替换净化。本仓库只取点按、章进度和渲染层整段隐藏，不换视觉、不改下载。

## 边界与异常

| 场景 | 处置 | 用户可见 |
|---|---|---|
| 无网络 / 超时 | 不适用 | 本战役无新请求 |
| 解析/抽正文失败 | 净化函数抛错则该章不净化，全部段落渲染 | 原文照显示，不当失败章 |
| 磁盘满或无权限 | 只影响偏好保存。章节文件不写。屏幕保持当前开关外观 | 现有偏好失败提示 |
| 重复书或重复章节 | 不适用 | 不改去重 |
| 用户取消 | 拖动未松手不换章。下载取消或结束（done/cancelled/error）后顶栏按收起规则 | running 结束前顶栏仍在 |
| API Key 缺失或失败 | 不适用 | 不碰 AI |
| 超长章节 / 大文件 | 超长段翻屏前进或后退不超过一屏，仍落在该段内 | 不跳过未读完的字 |
| 并发（多本/多任务） | 松手时若章节变短，index 夹到新末章。新列表为空则留在当前屏 | 正文区「无法打开这一章」 |

补充：

- 仅 `downloadProgress.status==='running'` 强制显示顶栏。`awaitingHuman`、done、cancelled、error、无进度都不强制显示，也不新增 awaitingHuman 文案。
- 章末已在最后一屏（距最大滚动不足 8px）时点右区：停住，不自动换章。章首点左区：停住，不换上一章。
- 点在按钮、链接、输入、滑杆上不触发三分区。存在未折叠选区时这次 mouseup 不触发。
- `hideSiteTail===false` 时所有章显示原文，本章开关无效。两者都开时只当前章显示原文。重开书只看 `hideSiteTail`。
- 同一章内滚动、开关目录、工具收起、最小化：本章显示原文保持。

## 内置整段规则

段落等于现有 `splitIntoParagraphs` 的一段。判断前删除该段内全部 Unicode 空白（含全角空格、换行、制表）。大小写 `toLowerCase`。标点保留。

命中任一则整段不渲染：

- R1 同时含「请收藏」与「本站」
- R2 同时含「请收藏」与「网址」
- R3 同时含「请收藏」与「地址」
- R4 以「最新网址」「最新地址」「手机用户请」「本章未完」之一开头
- R5 整段匹配 `^https?://\S+$` 或 `^www\.\S+$`

同一段命中多条只隐藏一次。同一段里两句分别有「请收藏」和「本站」且中间无空行，算命中 R1。「请收藏这封信」若不含本站/网址/地址、不以 R4 开头、又不是纯网址，则显示。不得再加规则，不得做成用户可编辑。

## 点击分区

只看指针相对 `.reader-content` 内容盒的 clientX。左 [0, 1/3)，中 [1/3, 2/3)，右 [2/3, 1]。与段首段尾无关。

## 翻屏落点

视口顶 T、底 B、一屏高 H。仅 `readingMode==='screen'` 时使用。连续滚动不调用。

下一屏：找与 (T, B) 相交且段底大于 B 的最前一段。没有则 `scrollTop=min(T+H, max)`。有且段高小于等于 H，则 `scrollTop=段首`。段高大于 H，则 `scrollTop=min(T+H, 段底-H)`，不把已滚过的上一段拉回。

上一屏：找段顶小于 T 且段底大于 T 的段。段高大于 H 则 `scrollTop=max(段首, T-H)`。段高小于等于 H 则 `scrollTop=段首`。没有切断段则 `scrollTop=max(0, T-H)`。已在 0 则停住。

## 进度拖动

按章节等分，不按字数。ratio 夹到 [0,1]。`index=clamp(round(ratio*(n-1)), 0, n-1)`。松手打开该章且 `scrollRatio=0`。拖动过程不写进度。松手后的进度沿用现有 readerProgress。

n 小于等于 0：无效果。n 等于 1：仍打开这一章章首。失败章照开，不跳到相邻成功章。目标章文件读失败走现有打开失败路径，不退回拖动前的章。

## 逐刀实现说明

- 无界面。独立复核已证实全量契约的两个既有失败：defaultLibraryPath 的 win32 分支使用宿主 join；backup 负例依赖不存在 Q 盘，在 Linux 会建相对目录。
- 仅允许 src/main/libraryPath.ts、libraryPath.test.ts、backup.test.ts：win32 分支按显式目标平台拼接；备份测试用受控 ENOENT 注入覆盖原有提示断言，不删断言、不跳过、不改备份产品逻辑。
- 验证 npm run build、npm test 退出码 0。无页面、IPC、数据格式、平台范围变化。
