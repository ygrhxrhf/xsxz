## 完成定义

1. 有阅读进度时，启动后主区是上次那本书的暖纸正文。顶栏和右侧「目录 / 进度 / 背景 / 字体」默认不可见。左侧书脊仍在，点书脊回书架。没有书时仍显示「阅读」「从书库打开一本书后在这里阅读」和「返回书库」。
2. 点正文中间三分之一，顶栏与右侧胶囊出现，顶栏含「搜索」。再点中间一次，或在没有已开面板时按 Esc，工具收起。点左侧三分之一上一屏，点右侧三分之一下一屏。滚轮仍滚动。左/右方向键仍是上一章/下一章。空格与 J/K 仍翻屏。
3. 底部进度条可拖。拖动时显示目标章名。松手打开该章并位于章首。拖到失败章停在该章，失败说明、重试、去浏览页仍在正文区。
4. 字体面板点「屏幕翻页」后，翻屏落在段落边界：被切断的短段下一屏从该段段首开始；一段高于一屏时只前进不超过一屏，不跳过该段剩余文字。点「连续滚动」后不再吸附。默认仍是连续滚动。
5. 默认开启净化。空行切成的一整段去掉空白后命中内置尾巴规则时，该段不显示。「请收藏这封信」这类叙述段仍显示。字体面板「本章显示原文」只让当前章临时显示原文，换章或重开书恢复净化。章节文件、划线、搜索、听书位置不改。关掉「净化」后重开书，尾巴段可见。
6. 当前书下载状态为 running 时，不点正文也能看见「已下 x / y 章」和「取消」。下载结束或取消后，顶栏回到默认收起。旧书不用重建。
