## 2026-03-22：纸面界面 weread-shell-20260322

| 决策 | 理由与边界 |
|---|---|
| 本战役按已记录阶段授权推进；代表页待批准时不启动依赖页面 | 用户选择「确认方案，专家组先做代表页，确认后批量实现」。W1.2 是代表页。W2.1–W2.4 依赖该批准 |
| 选定方向 A 纸面阅读 | 不选 B 封面书架首页，不选 C 双栏书桌。看书与下载同等重要，但打开仍进上次正文 |
| 四页一次做完，受代表页关口约束 | 阅读、书架、浏览、设置都重做。功能不删。代表页被否定只改视觉，不改已拍板功能 |
| 默认体验以 scheme「默认体验」为准，禁止再问 | 默认暖纸。工具默认不挡正文。夜樱不再是默认 |
| 数据与兼容以 scheme「数据与兼容」为准 | 向后兼容。不重建书库。唯一字段例外是 `Skin` |
| 方案内实现细节、拆刀、缩范围、跳过非主路径、验证抽查后合入默认分支均自主 | 不 push。可跳过列表为空。用户说「继续推进」视为合入授权 |
| 不得推翻 AGENTS.md 与 scheme「技术约束」 | 不打破钉死项。不升级 Naive UI 大版本 |
| 不得追加方案外的新产品方向 | 不含书城、社交、听书商城、新快捷键 |
| `Skin` 改为 `'paper' \| 'white' \| 'night'` | 旧 `sakura` 与 `minimal` 读入都当 `paper`。只改 `AppearancePrefs.skin`。下载、书库、AI 契约不动 |
| 顶栏与底栏分工 | 顶栏：书名、书架、搜索、标记、朗读、AI、沉浸、浏览、设置。底栏只有目录、进度、背景、字体。背景只切正文纸色：纸白、暖黄、柔灰、夜间。字体打开其余现有外观项，不删 |
| 书脊不是目录 | 书脊只放封面，点击展开书架。章节只在底栏目录 |
| 代表页不放全局换肤 | W1.2 全窗固定暖纸。全局三档只在 W2.3 设置页 |
| 核心文案固定，辅助句可简短拟定 | 不得改变按钮含义，不得保留樱花装饰文案 |
| 危险操作继续二次确认 | 移入回收站、删除站点规则、恢复备份沿用现文案 |
| 快捷键沿用，不新增 | 含不新增点正文中间呼出工具栏 |
| 异常规则只换位置 | 不断网改静默，不自动重试，不改单下载任务 |
| 设计委托 | 选定纸面方向内，对齐、间距、字号层级、圆角、普通辅助文案可由实现决定。不得删功能、改核心操作、数据策略或技术栈 |

## 继承约束

- UI 仅中文。章节正文只渲染纯文本，禁止 `v-html`。
- 浏览与下载共用 `persist:novel`。下载用隐藏 `webContents` 逐章 `loadURL`，禁止裸 `fetch` 当下书主路径。
- 无 native 模块。
- 不碰未跟踪的用户书库目录。
