# U1.1 重入阅读页工具默认收起

- 起始 HEAD：`b37237521c3dc1e4df40eeb049d2195dbee7b29b`（分支 `agent/session-2ab112d2`）
- 坐标：U1.1，任务 `U1.1-reentry-4`

## 根因

`src/renderer/App.vue:285` 用 `v-show="tab === 'reader'"` 常驻挂载 `ReaderPage`，组件从不 unmount。
`toolsVisible` 只在 `onMounted` 期间取初始 `false`（`src/renderer/pages/Reader.vue:152`），
离开阅读页去书库再点书卡回来时组件不重建，`toolsVisible` 仍是上次的 `true`，
所以顶栏（`Reader.vue:2097` 起的 `.reader-toolbar`）和底栏 `.reader-bottombar` 原样可见，只有整页重载才恢复默认。
即：没有任何「本页重新可见」的信号参与工具层复位。

## 改动点

- `src/renderer/pages/Reader.vue:163` 新增 `readerRootRef` + `readerOnScreen` + `readerVisibilityObserver` 状态；
  `Reader.vue:2097` 根元素加 `ref="readerRootRef"`。
- `src/renderer/pages/Reader.vue:606` 新增 `collapseToolsForEntry()`：只复位工具层
  （`toolsVisible=false`、`temporaryToolReveal=false`、`pointerInToolbar=false`、清隐藏定时器），不碰阅读位置与沉浸模式。
- `src/renderer/pages/Reader.vue:619` `applyReaderOnScreen()` 用 `shouldResetReaderToolsOnEntry(was, now)` 判定重入。
- `src/renderer/pages/Reader.vue:625` `startReaderVisibilityWatch()`：在 `onMounted`（`:1922`）用 `ResizeObserver`
  观察根元素真实尺寸。`v-show` 切 `display:none` 时尺寸归零，切回来恢复——这是「重入本页」的真实信号，无 `setTimeout` 硬等、无 `location.reload`。
- `Reader.vue:1069` `loadBook` 换书时也复位：`if (book.value?.id !== bookId) collapseToolsForEntry()`（换书同样算进入阅读页）。
  该行放在 `assistantBudgets.value = {}` 之后，保持既有契约断言文本不变。
- `Reader.vue:2076` 附近 `onUnmounted` 调 `stopReaderVisibilityWatch()` 断开观察者。
- `src/renderer/pages/readerHelpers.ts:170` 新增纯函数 `shouldResetReaderToolsOnEntry(wasOnScreen, isOnScreen)`：
  只有 `false -> true` 才算重入；首次观测（`null`）只登记，常驻可见期间不收起，避免打断正在阅读的人。

未回退的行为：点正文中区显隐（`toggleReaderTools`）、左右区翻页（`onContentZoneMouseup`）、Esc 收起（`onReaderKeydown`）、
下载 running 挡 Esc（`downloadKeepsTools`）均未改动；`m`/`Alt` 沉浸态切换逻辑未改动。
