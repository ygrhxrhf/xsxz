| 位置 | 原状 | 缺口 |
|---|---|---|

结论：进度条此前**完全没有拖动实现**，是纯展示层。要补的是「反算 + 拖动接线 + 浮标」三件。

## 改动点

`src/renderer/pages/readerHelpers.ts`（+47 行）
- 新增 `chapterIndexFromBookRatio(ratio, totalChapters)`：`approximateBookRatioFromIndex` 的反解，`floor(clamp(ratio) * total)` 再夹到 `[0, total-1]`；章节数非法返回 `-1`。
- 新增 `progressScrubTarget(chapters, ratio)`：返回 `{ index, chapter, scrollRatio: 0 }`，**松手落点固定章首**；空列表返回 `null`。
- 新增 `progressScrubLabel(chapter, index)`：`第 N 章 · 标题`，标题空白时只留章序。

`src/renderer/pages/Reader.vue`（+176/-1 行）
- 状态：`scrubRatio` / `scrubTarget` / `scrubLabel` / `scrubOrdinal` / `scrubTitle` / `scrubbing` / `scrubPercent` / `progressTrackRef` / `scrubPointerId`。
- 拖动：`startProgressScrub`（左键 + 有章节才起、`setPointerCapture`、`revealTools`）、`moveProgressScrub`（**只更新 `scrubRatio`，不 openChapter**）、`endProgressScrub`（`pointercancel` 直接取消；否则 `openChapter(target.chapter, 0)`）、`cancelProgressScrub`（`lostpointercapture`）。
- 键盘：`onProgressTrackKeydown`，Left/Down 上一章、Right/Up 下一章、Home/End 首末章，`stopPropagation` 避免被阅读器全局快捷键二次处理。
- 模板：轨道加 `ref` + `role="slider"` + `tabindex="0"` + `aria-roledescription` + `aria-valuemin/max/now/valuetext`（**保留原 `:aria-label="bookProgressDetail"` 与 `:title`**），6 个指针/键盘监听；新增 `scrub-preview` 预览填充与 `aria-live="polite"` 的 `.reader-progress-scrub-hint` 浮标。
- 样式：`.reader-progress-track.scrubbing`（8px / grabbing）、`:focus-visible` 描边、`.scrub-preview`、`.reader-progress-scrub-hint` 浮标（`pointer-events: none`，`bottom: calc(100% + 8px)` 贴在轨道上方不遮正文）。
- 明确**未动**：`onScroll`、`readerProgress.schedule()`、`captureProgressWrite`、`currentChapterRatio`、`openChapter` 的写盘前置与 navEpoch，连续滚动位置与进度写盘语义零改动。

## 断言名

`readerHelpers.test.ts > 进度条按章拖动`
1. `maps a book ratio onto the chapter the bar points at` —— 锁「按章映射」：0→c1、1/3→c2、1→c3，并反向验证每章首比例 ≤ ratio < 下一章首比例。
2. `survives degenerate inputs without inventing a chapter` —— 章节数 0/NaN → `-1`；空列表 → `null`。
3. `drops onto the start of the target chapter` —— 锁「松手落章首」：0.96 也必须 `scrollRatio === 0`。
4. `labels the floating hint with chapter ordinal and title` —— 浮标文案。

`Reader.accessibility.contract.test.ts > Reader U1.2 progress scrubbing`
5. `shows the target chapter name while dragging, not after release` —— 拖动中显示章名，且 `moveProgressScrub` 块内不含 `openChapter`。
6. `opens the target chapter at its start on release` —— `progressScrubTarget` 返回 `scrollRatio: 0`、松手调 `openChapter(target.chapter, 0)`。
7. `keeps the track keyboard reachable and its old labels` —— `role="slider"` / `tabindex="0"` / 原 `aria-label` / focus 描边 / 失败章重试与「去浏览页」入口仍在。
