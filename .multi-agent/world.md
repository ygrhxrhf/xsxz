## 现状

Windows 单机 Electron + Vue 3 + Naive UI。阅读页在 `src/renderer/pages/Reader.vue`。暖纸壳战役 weread-shell-20260322 已完成：有进度时进入正文，左侧书脊，右侧胶囊为目录/进度/背景/字体。

已有：连续滚动与屏幕翻页、字号行距纸色、目录抽屉、搜索、划线、听书、AI、自动滚屏、底部双进度条、左右热区翻章。屏幕翻页按整屏高度切，会切断段落。进度条只展示，不可拖。顶栏和右侧胶囊默认占着正文。每段悬着「从此段朗读」。

`ReaderPrefs` 无 `hideReaderChrome` / `hideSiteTail`。站点规则 `bodyCleanPatterns` 在下载入库前按域名删段，阅读器渲染层没有第二套整段尾巴隐藏。章节正文纯文本，禁止 `v-html`。

| 进度可拖 | 阅读器常见能力 | 可落地 | 按章等分，松手到章首 |

## 与目标的差距

打开书仍先看见工具。翻屏切断段落。进度不能拖。站点尾巴要等用户点清正文才会改文件，读的时候仍在。
