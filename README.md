# 小说浏览器（spbf）

Windows 单机阅读工具：在内置浏览器里**浏览**网页，对当前这本书点「**下载本书**」，进入本机**书库**用**阅读**器接着看；需要时在设置里填自己的 API Key，用 **AI** 清正文、摘要、翻译、聊书。软件不附带任何官方 Key。

产品路径：**浏览 → 下载本书 → 书库 / 阅读 → 自备 Key 的 AI**。

## 开发命令

```bash
npm run dev
npm test
npm run build
```

- `npm run dev`：启动 Electron 开发窗（electron-vite）
- `npm test`：跑 vitest（不 watch）
- `npm run build`：编译主进程 / 预加载 / 渲染进程

## 书库路径

默认书库在 `D:\spbf\library`（已 gitignore）。设置页可改路径，立刻生效，不会把旧书搬过去。测试请改到临时目录，不要动用户已有书。

## AI

设置里自行填写兼容 OpenAI 的 `baseURL`、模型名和 API Key。仓库与安装包**不附带 Key**。没填 Key 时，清正文 / 摘要 / 翻译 / 聊书会明确失败，浏览、下载、阅读不受影响。

## 站点规则

设置页可按域名保存书名 / 作者 / 目录 / 正文四条可选 CSS；下载时该站规则优先，没命中或非法选择器再走通用提取。规则只存在本机，没有在线市场。

## 这不是什么

这是**个人阅读工具**。明确不做：整站镜像、选择器市场、打码、IP 池、破解付费墙、账号 / 云同步。用户对自己粘贴的网址和下载内容负责。
