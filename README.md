# 小说浏览器（spbf）

Windows 单机阅读工具：在内置浏览器里**浏览**网页，对当前这本书点「**下载本书**」，进入本机**书库**用**阅读**器接着看；需要时在设置里填自己的 API Key，用 **AI** 清正文、摘要、翻译、聊书。软件不附带任何官方 Key。

产品路径：**浏览 → 下载本书 → 书库 / 阅读 → 自备 Key 的 AI**。

浏览 View 与下载 View 共用 `persist:novel` 分区，对外发送标准 Chrome UA（不含应用名和 Electron 标识），站点登录态两边通用。

下载前可预览目录和正文样本；下载后会提示疑似质量问题，书库可逐章检查、编辑纯文本正文或更正链接重下。设置页支持站点规则试运行、复制校验后搬迁书库，以及每周本地自动备份（保留最近五份自动备份）。

书库可从分类 / 作者 / 搜索结果列表页做整站镜像：一次任务把列表里的书批量下载进书库，中断后可从同一列表页继续。

## 开发命令

```bash
npm run dev
npm run typecheck
npm test
npm run build
```

- `npm run dev`：启动 Electron 开发窗（electron-vite）
- `npm run typecheck`：检查主进程、预加载和渲染进程的 TypeScript 类型
- `npm test`：跑 vitest（不 watch）
- `npm run build`：编译主进程 / 预加载 / 渲染进程
- `npm run dist:local`：打 Windows 安装包（走 npmmirror 取 builder 二进制），产物在 `release/小说浏览器 Setup 0.1.0.exe`
- `npm run pack:local`：只生成免安装目录 `release/win-unpacked/`

端到端（两条都会真开一次应用窗口，需先 `npm run build`）：

- `npm run e2e:startup`：书库目录不可用时的启动兜底（弹窗说明 → 换目录 → 继续启动）
- `npm run e2e:ocr`：图片化正文走 OCR 入库（起本地夹具站点，真认字，核对 `unlockedBy=ocr`）

## 打包

- 安装包图标取 `build/icon.ico`（深蓝布面 + 摊开的书页 + 烫金书脊，多尺寸 16–256）。
- 没有配代码签名证书，Windows 首次运行会提示「未知发布者」，属预期；个人自用不必签名。
- 安装包只装程序，不含书库；书库仍在你设置的路径（默认 `%USERPROFILE%\spbf\library`），卸载不会删书。
- 安装器是 NSIS（`oneClick: false`，可选安装目录、桌面/开始菜单快捷方式）。

## 书库路径

默认书库在当前用户家目录下的 `spbf/library`（Windows 为 `%USERPROFILE%\spbf\library`）。设置页可改路径，立刻生效，不会把旧书搬过去；清空该项则回到默认目录。测试请改到临时目录，不要动用户已有书。

## AI

设置里自行填写兼容 OpenAI 的 `baseURL`、模型名和 API Key。可用「测试连接」探活。仓库与安装包**不附带 Key**。没填 Key 时，清正文 / 摘要 / 翻译 / 聊书会明确失败，浏览、下载、阅读不受影响。

## 站点规则

设置页可按域名保存书名 / 作者 / 目录 / 正文四条可选 CSS；下载时该站规则优先，没命中或非法选择器再走通用提取。浏览页可点「配置本站规则」，把当前站域名预填进设置。

规则市场可订阅别人写好的抽取规则并一键应用到本机；市场条目只含 CSS 选择器，不含任何凭据。账号与云同步可把设置与站点规则同步到自己的云端，书库正文、API Key 与批注不上云。

## 本机导出

书库卡片可把已下好的章节合成 txt 或 epub，保存到你选的文件夹。只走本机，不上传、不分享。

## 这不是什么

这是**个人阅读工具**。多设备同步、社区、分享导出到公网都在第一版之外。用户对自己粘贴的网址和下载内容负责。
