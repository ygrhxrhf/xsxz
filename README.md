# 小说浏览器（spbf）

Windows 单机阅读工具：在内置浏览器里**浏览**网页，对当前这本书点「**下载本书**」，进入本机**书库**用**阅读**器接着看；需要时在设置里填自己的 API Key，用 **AI** 清正文、摘要、翻译、聊书。软件不附带任何官方 Key。

产品路径：**浏览 → 下载本书 → 书库 / 阅读 → 自备 Key 的 AI**。

浏览 View 与下载 View 共用 `persist:novel` 分区，对外发送标准 Chrome UA（不含应用名和 Electron 标识），站点登录态两边通用。

下载前可预览目录和正文样本；下载后会提示疑似质量问题，书库可逐章检查、编辑纯文本正文或更正链接重下。设置页支持站点规则试运行、复制校验后搬迁书库，以及每周本地自动备份（保留最近五份自动备份）。

## 开发命令

```bash
npm run dev
npm run typecheck
npm test
npm run build
```

- `npm run dev`：启动 Electron 开发窗（electron-vite）
- `npm run typecheck`：检查主进程、预加载和渲染进程的 TypeScript 类型
- `npm test`：跑 vitest（不 watch）
- `npm run build`：编译主进程 / 预加载 / 渲染进程

## 书库路径

默认书库 Windows 在 `D:\spbf\library`、其他系统在 `~/spbf/library`。设置页可改路径，立刻生效，不会把旧书搬过去；清空该项则按当前系统回到默认目录。测试请改到临时目录，不要动用户已有书。

## AI

设置里自行填写兼容 OpenAI 的 `baseURL`、模型名和 API Key。可用「测试连接」探活。仓库与安装包**不附带 Key**。没填 Key 时，清正文 / 摘要 / 翻译 / 聊书会明确失败，浏览、下载、阅读不受影响。

## 站点规则

设置页可按域名保存书名 / 作者 / 目录 / 正文四条可选 CSS；下载时该站规则优先，没命中或非法选择器再走通用提取。规则只存在本机，没有在线市场。浏览页可点「配置本站规则」，把当前站域名预填进设置。

## 本机导出

书库卡片可把已下好的章节合成 txt 或 epub，保存到你选的文件夹。只走本机，不上传、不分享。

## 这不是什么

这是**个人阅读工具**。明确不做：整站镜像、选择器市场、打码、IP 池、破解付费墙、账号 / 云同步。用户对自己粘贴的网址和下载内容负责。
